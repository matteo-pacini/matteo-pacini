### Hi, I'm Matteo 👋

Senior / Lead Software Engineer, based in the UK and working remotely. I'm a full-stack engineer with deep mobile expertise.

I work across the whole product: Go services on Kubernetes with Temporal workflows and protobuf contracts, React Native apps with native Swift and Kotlin modules, release pipelines and reproducible Nix tooling. Before that I spent over a decade shipping Apple software in healthcare, fintech and consumer products.

I'm very interested in LLMs and AI. Coding agents are central to how I work: I run several in parallel and write agent skills that encode team conventions and automate releases. I've also built with LLMs directly, from RAG pipelines and fine-tuning to on-device inference.

I run NixOS everywhere and was a Nixpkgs maintainer from 2024 to 2026.
